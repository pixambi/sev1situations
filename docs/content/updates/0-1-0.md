The first release of Sev1 Situations.

## What is in it

- The run page, with steps, hints, verification, notes, ratings and rollback to a reset point.
- The Cluster, Logs and Terminals tabs, and node actions: stop, start, remove and revive.
- Reports: one saved per run, viewable in the app and exportable as a single offline HTML page or raw data.
- Vault, with a Raft cluster and an optional transit seal provided by a second Vault.
- Boundary, with a database, controllers behind a load balancer, a worker and a target host.
- Six scenarios: Vault Sandbox, Raft Lost Quorum, Broken KMS, Boundary Sandbox, Authorize-Session 403 and Session Limits.
- Offline documentation, and a command line for listing, validating and creating scenarios.

## What is not in it

- The Enterprise scenarios (HSM auto-unseal, DR and performance replication, session recording) are not built yet.
- Enterprise editions have not been tested.
- The build is not signed or notarised, so macOS needs `xattr -cr` on first launch. See [Getting started]({{< relref "/getting-started" >}}).
