---
title: Reports
description: What a report holds and how to keep it.
weight: 4
---

Every run saves one report when it ends, whether it was finished or ended early.

A report holds the scenario, the instructor and trainee, the time of each step, the notes and ratings, and the notable events.
It never holds a credential: every secret of the run is removed before it is saved.

The Reports tab lists them. **Open** shows the report in the app. **Export** saves it as a single HTML page that works offline, or as the raw data. **Delete** removes it for good.

Reports are kept in the application data directory, in a `reports` folder, one file per run. They are never overwritten.
