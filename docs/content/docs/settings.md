Open Settings from the app menu.

- **Instructor name** is filled into the Start form.
- **Vault Enterprise license** and **Boundary Enterprise license** are needed for an Enterprise edition. A license is stored in
  the settings file with owner-only permissions, shown masked, and only put into a deployment that needs it.

{{< callout note >}}
Enterprise editions have not been tested yet. Community editions are the supported path.
{{< /callout >}}
